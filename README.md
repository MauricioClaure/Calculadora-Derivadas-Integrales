# Calculadora de Derivadas e Integrales

## Descripción

Proyecto desarrollado en C# Windows Forms para la materia de Cálculo II.

La aplicación permite resolver derivadas, integrales indefinidas e integrales definidas de distintas funciones matemáticas.

## Funcionalidades

- Derivación de polinomios
- Derivación de funciones trigonométricas
- Derivación de funciones exponenciales
- Derivación de funciones logarítmicas
- Regla del producto
- Regla del cociente
- Regla de la cadena
- Integrales indefinidas
- Integrales definidas
- Historial de operaciones
- Validación de entradas

## Tecnologías Utilizadas

- C#
- Windows Forms
- Visual Studio 2019
- GitHub

## Requisitos

- Windows 10 o superior
- Visual Studio 2019 o superior
- .NET Framework compatible con el proyecto

## Instalación

1. Clonar o descargar el repositorio.
2. Abrir el archivo `.sln` en Visual Studio.
3. Compilar la solución.
4. Ejecutar el proyecto.
